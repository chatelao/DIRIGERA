# Appendix E: Related Open-Source Projects

This appendix lists open-source projects related to the IKEA DIRIGERA Smart Home Hub, categorized by platform, programming language, and ecosystem integration.

## Official IKEA Distributions

- **[ikea-oss-distributions/DIRIGERA-hub](https://github.com/ikea-oss-distributions/DIRIGERA-hub)**: Official open-source software distributions and licensing information for the IKEA DIRIGERA hub.

## Client Libraries & SDKs

### Python
- **[Leggin/dirigera](https://github.com/Leggin/dirigera)**: Unofficial Python client library for controlling the IKEA Dirigera Smart Home Hub.
- **[mattias73andersson/dirigera-client-poc](https://github.com/mattias73andersson/dirigera-client-poc)**: Proof-of-concept Python client for interacting with the IKEA Dirigera hub API.

### JavaScript / TypeScript
- **[lpgera/dirigera](https://github.com/lpgera/dirigera)**: Unofficial JavaScript and TypeScript client library for IKEA's DIRIGERA smart home hub.
- **[lpgera/dirigera-web](https://github.com/lpgera/dirigera-web)**: Progressive Web Application (PWA) for controlling Dirigera smart home devices.

### Java
- **[dvdgeisler/DirigeraClient](https://github.com/dvdgeisler/DirigeraClient)**: Java-written client API to interface with IKEA's DIRIGERA smart home hub.
- **[salex-org/ikea-dirigera-client](https://github.com/salex-org/ikea-dirigera-client)**: Java client library and command-line interface (CLI) for the IKEA DIRIGERA Smart Home Hub.

### Rust
- **[bombsimon/dirigera-rs](https://github.com/bombsimon/dirigera-rs)**: Rust client library for controlling and interacting with the IKEA Dirigera hub.

## Smart Home & Platform Integrations

### Home Assistant
- **[sanjoyg/dirigera_platform](https://github.com/sanjoyg/dirigera_platform)**: Custom Home Assistant integration for the IKEA Dirigera Platform.
- **[matthewdavidlloyd/ha-ikea-dirigera](https://github.com/matthewdavidlloyd/ha-ikea-dirigera)**: Home Assistant integration for DIRIGERA hub devices.
- **[TheMrBooyah/hassio-dirigera-client](https://github.com/TheMrBooyah/hassio-dirigera-client)**: Home Assistant client integration for DIRIGERA.

### Homebridge
- **[uboness/homebridge-dirigera](https://github.com/uboness/homebridge-dirigera)**: Homebridge plugin enabling Apple HomeKit support for devices connected to the IKEA DIRIGERA hub.

### Homey
- **[theeuwes-it/homey-dirigera-gateway](https://github.com/theeuwes-it/homey-dirigera-gateway)**: Homey application for integrating the IKEA Dirigera Gateway.
- **[favoretti/net.favoretti.ikea.dirigera](https://github.com/favoretti/net.favoretti.ikea.dirigera)**: IKEA DIRIGERA app for Homey platform.

### Node-RED
- **[zinen/node-red-contrib-dirigera](https://github.com/zinen/node-red-contrib-dirigera)**: Node-RED nodes for controlling devices connected to the IKEA Dirigera hub.

## Monitoring & Other Tools

- **[rtoma/dirigera-prometheus-exporter](https://github.com/rtoma/dirigera-prometheus-exporter)**: Prometheus exporter for retrieving metrics from the IKEA Dirigera Hub and attached devices.
- **[vchlum/smart-home](https://github.com/vchlum/smart-home)**: GNOME Shell extension for controlling smart home devices including IKEA Dirigera on local networks.
- **[maceq687/dirigera-max](https://github.com/maceq687/dirigera-max)**: Max MSP package for controlling IKEA smart lights over local network using the Dirigera gateway.
